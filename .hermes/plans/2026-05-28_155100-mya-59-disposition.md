### Workstream 3 — Publish + onboard
1. **Publish the verdict.** Write `governance-verdict-mya-59.md` under issue documents on MYA-59 — terse: 3 ship, 9 don't, why. One paragraph each. No ceremony.
2. **Onboarding link.** Update the agent onboarding template (or wherever new-agent briefings are anchored) to point at the verdict doc, so any future agent reading "what's our governance posture" lands here, not on the unfiltered Holacracy book.
3. **Daily budget sentinel cron (E).** Wire a one-shot daily check that:

   - Posts a one-line summary to ops topic if Opus % of total > 30 OR any agent > 80% of monthly cap
   - Stays silent otherwise (watchdog pattern, `no_agent: true` cron with a python script)
4. **24h cost replay (V).** After 24h with the new model assignments, query cost_events grouped by model. Validate Opus drop ≥60% from baseline. If yes, log success on MYA-59. If no, file an issue under "rightsizing-iteration-2" and don't pretend it's done.
